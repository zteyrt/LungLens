## 完整 CT 结节级检测

同一原始11例 Val CT、44个参考结节。每个模型各自选择验证集上满足 `FP/scan ≤4` 的最佳观察敏感度操作点，指标不等同于预先固定阈值的独立 Test 结果。

| 指标 | V4.1 | V5 |
|---|---:|---:|
| 检出参考结节 TP | 33 | 35 |
| 漏检 FN | 11 | 9 |
| 结节级敏感度 | 75.00% | 79.55% |
| 假阳性 FP | 35 | 38 |
| FP/scan | 3.182 | 3.455 |

V5 最佳观察点：`min_slices=2`、`score≈0.4130058885`，TP=35、FP=38、FN=9。在较低阈值0.05时，V5生成的候选可覆盖38个结节（86.36%），但有293个FP（26.636 FP/scan）；尚未满足“≥85%且≤4 FP/scan”的联合目标。

### 评估定义

- `Sensitivity = TP / (TP + FN)`，按参考结节个数统计，而非二维图片个数。
- `FP/scan = FP / 验证 CT 数量`，FP按项目实现的结节匹配/排除标注逻辑统计。
- 置信度阈值变化会同时影响TP、FN、FP；必须在**同一阈值和同一后处理配置**下检查两项目标。
- `min_slices` 表示三维候选至少出现在多少个切片上。

### 评估局限

1. 已实现的排除标注参考 LUNA16，但不是官方 FROC 工具的完整复刻。
2. V5 完整 CT 推理有过一次 `WARNING NMS time limit ... exceeded`，尚需在无超时条件下复核。
3. 验证集已用于阈值优化，不能把这里的最佳操作点当成独立泛化性能。
4. 预留的7例独立 Test 尚需在模型、阈值和后处理固定后做最终评估。
5. 训练使用球形截面近似框，部分微小框及未标注的可疑结构可能引入弱标签噪声。
6. 3D CNN假阳性抑制实验的内部样本分类AUC约0.905，但旧版整例 CT FROC 未优于原YOLO基线；两类评价不能混为一谈。

## 下一步实验

- 复核 NMS 超时对候选集的影响，并确保 V4.1/V5 推理配置完全相同。
- 统一漏检、排除标注和FROC脚本的匹配口径。
- 针对低置信度真阳性与肺部非结节结构的假阳性进行候选特征分析。
- 固定所有调参后再评估独立 Test，禁止依据 Test 成绩反复改阈值。
